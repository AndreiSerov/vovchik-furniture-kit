# vovchik-furniture-kit glossary

Code, docs and logs use these terms. `/grill-with-docs` adds to this file as terms get settled.
Человеку показываем русский термин, в коде используем английский.

| Term | Code | Meaning | Avoid |
|---|---|---|---|
| Мастер | master | Мебельщик-одиночка, пользователь системы: сам общается с клиентом, закупает, пилит, кромит, сверлит, собирает | салон, дизайнер, менеджер |
| Мастерская | workshop | Данные мастера в YAML: оборудование, конструкция, материалы, фурнитура, труд, цены, техника | настройки, конфиг |
| Мок | mock | Файл мастерской с `mock: true`: значения-заглушки, которые мастер ещё не заменил. Любой вывод, посчитанный с моком, несёт пометку «МОК-ДАННЫЕ — НЕ ДЛЯ КЛИЕНТА» | тестовые данные, демо |
| Заказ | order | Одна кухня одного клиента. Номер `ГГГГ-NNN-фамилия`, например `2026-047-petrov` | проект (о заказе целиком) |
| Бриф | brief | Требования клиента до замера, собранные скиллом `kitchen-brief` | ТЗ, анкета |
| Проект | project | Конструкция кухни заказа: стены, модули по порядку, материалы, наполнение, техника | дизайн, раскладка (о проекте целиком) |
| Версия проекта | project version | Неизменяемая копия проекта с номером. Новая версия появляется при каждом импорте изменённого проекта | ревизия, редакция |
| Стена | wall | Стена помещения с меткой `A`, `Б`. Модули на стене идут по порядку от начала стены | сторона |
| Ряд | row | Нижний или верхний ряд модулей на стене. Пенал входит в оба ряда | ярус, уровень |
| Модуль | module | Один шкаф проекта с меткой: `П1` пенал, `Н1` нижний, `В1` верхний | шкаф, блок, секция, корпус (о модуле целиком) |
| Шаблон | template | Правило движка, которое превращает модуль в детали и фурнитуру: `base_door`, `wall_lift`, `tall_oven` и др. | тип шкафа, пресет |
| Деталь | part | Одна плоская деталь из листа или фасад. Имеет маркировку, размеры, материал, кромку по 4 сторонам и положение в модуле | панель, заготовка |
| Маркировка | part ID | Уникальная метка детали вида `Н1-бок-Л`: модуль, имя, уточнение | артикул, код |
| Фурнитура | hardware | Покупные изделия из `hardware.yaml`: петли, направляющие, конфирматы, опоры и т. д. | комплектующие |
| Кромка | edge | ПВХ-кромка на торце детали. Кромление — её приклейка | обкладка |
| Угловое смещение | corner offset | Длина соседней стены, которую занимает угловой модуль, хотя он числится на другой стене | заход, нахлёст |
| Ниша | niche | Проём модуля под встроенную технику | отсек |
| Раскрой | cutting layout | Гильотинная укладка деталей на листы с порядком резов. Карта раскроя — его PDF | раскладка (о листе), нарезка |
| Закупка | purchase list | Что купить: целые листы, метраж кромки, фурнитура упаковками, по магазинам | заказ поставщику |
| Смета | estimate | Внутренний расчёт мастера: себестоимость, труд, наценка, цена | калькуляция |
| КП | quote | Коммерческое предложение клиенту: итог, предоплата, сроки, без себестоимости и наценки | счёт, смета (о документе клиенту) |
| Вывод | output | Результат, посчитанный из версии проекта: файл или JSON. Хранит версию-источник | отчёт, артефакт |
| Устаревший вывод | stale output | Вывод, чья версия-источник старше текущей версии проекта | неактуальный |
| Журнал | log | Записи заказа: что сделано, решения клиента, что дальше. Из него `kitchen status` собирает `status.md` | история, лента |
