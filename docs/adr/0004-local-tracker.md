# 0004. Спеки и тикеты — локальные файлы, Issues — только баги

Статус: принято, 2026-11-13.

## Решение

- Спека на этап — `docs/specs/stage-N-<название>.md`. Тикеты с номерами задач ТЗ (`0.1`, `1.3`, …) — разделы внутри своей спеки.
- `PROGRESS.md` — источник правды о статусе задач. Его читают в начале каждой сессии.
- GitHub Issues — только баги. Для них заведены пять триажных меток.
- Ветка на этап (`stage-N`), коммит на тикет с префиксом номера (`1.3: …`). PR мержит пользователь.

## Последствия

`docs/agents/issue-tracker.md` описывает это правило, и скиллы `/to-spec`, `/to-tickets`, `/implement` пишут в файлы, а не в Issues.
