## Тикет 33 (хотфикс мастерской)

Из повторного ревью 933f927 (находки 3–6, 9, 10); находки 1, 2, 7, 8 закрыты коммитом ea8c5cb.

- Повтор ключа внутри словаря, подмешанного прямо на месте (`{<<: {цена: 1, цена: 9}}`), не ловится (`workshop.py:64-77`).
- Ложный «повторный ключ» на законном YAML: якорный словарь с `<<` и перекрытием лежит глубже подмешивающего (`workshop.py:75`). Лечится проверкой повторов на этапе композиции узлов; закрывает и предыдущую.
- `ножки.высота: 0` отклоняется, хотя число ножек 0 разрешено — кухня на цокольной коробке не описывается. Вопрос мастеру.
- AST-проверка `round`/`int` обходится через локальную переменную (`cutting.py:262`); результат сейчас верный.
- `RecursionError` на YAML с тысячами уровней вложенности; ввод искусственный, так было и до тикета.
- `пропил: '3.2'` в кавычках принимается как число (нестрогий `float`).

## Тикет 18 (КП)

Из третьего ревью 1c885e9 (тикет принят) и прежних кругов.

- Диапазоны меток материалов идут через ряды и буквы: «(П1–Н2, Н4–В6)» при разном корпусе не расшифровать клиенту — строить диапазоны только внутри ряда или буквы. Вопрос мастеру (вывод для клиента).
- Бутылочница названа «с одной дверью», хотя фасад выдвижной — вопрос мастеру.
- Модель прибора `type: other` и запасной вид «(N шт.)» идут клиенту без пометки ПРОВЕРИТЬ МАСТЕРУ; модель может содержать марку.
- DECISIONS «КП»: пункт (2) «то же для корпуса и столешницы» противоречит пункту про одну столешницу без меток — переписать на месте.
- Схема проекта всё ещё объявляет `countertop` у ряда и модуля, хотя импорт его отклоняет.
- Тесты: мутант «фасад у модуля без дверей» и недостижимый `_name`-фолбэк; нет теста `countertop_override` в `check_project` и `parts`; слабое утверждение `tests/test_quote.py:731`.
- Фасад узнаётся по имени детали «фасад» в `quote.py`, а в `compute_parts` — по `area_m2` (одно правило — два места).
- `describe_module` строит модуль второй раз ради фурнитуры.
- `для_клиента_мн` без `для_клиента` молча не используется; `check-workshop` мог бы предупреждать о вставке шаблона без клиентского названия.
- Черновик `quote --project` с находками `error` не предупреждает (как `estimate --project`).
- `quote.json` содержит внутренние поля (`source`, `mock_files`) — КП клиенту уходит только PDF.
- Без `master.yaml` не работает ни одна команда (так задумано для файлов мастерской).
