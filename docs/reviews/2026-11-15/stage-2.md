### 1. БЛОКИРУЕТ. Дробные пропил, обрезка и размер листа молча округляются
- **Где:** `/Users/andreiserov/Developer/vovchik-furniture-kit/engine/kitchen/cutting.py:259-261` (`round(ws.equipment.saw.kerf)` и соседние), `cutting.py:254-255` (`_material_axes`), `/Users/andreiserov/Developer/vovchik-furniture-kit/engine/kitchen/api.py:966-968`. Поля в `models.py:64-69` имеют тип `Num` (float), поэтому `check-workshop` дробное значение принимает.
- **Сбой:** при `пропил: 4.5` детали кладутся с зазором 4 мм, в выводе стоит «пропил 4 мм» (банковское округление). При `пропил: 3.2` зазор 3 мм. При `обрезка_по_периметру: 12.5` берётся 12. Лист `[2800.6, 2070.4]` считается как 2801×2070, то есть больше настоящего. Ни ошибки, ни предупреждения нет. Детали выйдут меньше номинала на 0.2–0.5 мм за каждый рез в полосе, а 3.2 мм — обычная толщина диска.
- **Нарушает:** user story 2 («чтобы детали вышли в размер») и «Нет молчаливо неверного вывода» из `CODING_STANDARDS.md`.
- **Вдобавок:** `checks.part_fit_findings` считает поле с неокруглённой обрезкой, а раскрой — с округлённой. При 10.5 мм проверка даёт поле 2779, раскрой — 2780.
- **Подтверждено запуском:** да. На текущем моке (4 / 10 / 3200, всё целое) не срабатывает.
- **Воспроизведение** (падает для обоих значений):
```python
@pytest.mark.parametrize("kerf", ["4.5", "3.2"])
def test_fractional_kerf_is_not_silently_rounded(home, kerf):
    path = home / "workshop/equipment.yaml"
    path.write_text(path.read_text().replace("пропил: 4", f"пропил: {kerf}"))
    try:
        result = api.cut_from_project(FIXTURES / "petrov_project.json", home)
    except KitchenError:
        return  # русская ошибка «пропил должен быть целым» — допустимое исправление
    assert result.kerf == float(kerf)
    for m in result.materials:
        for s in m.sheets:
            for i, a in enumerate(s.placements):
                for b in s.placements[i + 1 :]:
                    gap = max(b.x - a.x - a.w, a.x - b.x - b.w, b.y - a.y - a.h, a.y - b.y - b.h)
                    assert gap >= float(kerf), (a.part, b.part, gap)
```
- **Механическая проверка на будущее:** сделать `Saw.kerf`, `Saw.max_cut_length`, `SheetTrim.perimeter_trim`, `SheetMaterial.sheet`, `Countertop.sheet` строго целыми в `models.py`. Тогда `kitchen check-workshop` отклонит дробное. Альтернатива — пропил округлять вверх с предупреждением. Плюс структурный тест: в `cutting.py` и `api.py` нет `round(` над полями мастерской.
